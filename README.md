# 🤖 Ário - Assistente Financeiro Pessoal no WhatsApp

O **Ário** é um assistente financeiro inteligente estruturado inteiramente em fluxos de **n8n**, integrado à API oficial do WhatsApp, Inteligência Artificial (Groq/Llama) e Baserow para controle de orçamento familiar baseado no método de "potinhos".

## 🚀 O que este projeto faz?
- **Gestão de Orçamento por Categorias (Potes):** O usuário define limites de gastos e o bot calcula metas diárias e semanais automaticamente[cite: 2].
- **Lançamentos via IA:** Processa mensagens de texto e áudio enviadas no WhatsApp, categorizando os gastos de forma inteligente[cite: 2].
- **Geração de Relatórios:** Cria planilhas automatizadas com o extrato do período e envia arquivos em Excel direto no chat[cite: 2].
- **Assinaturas:** Contém fluxos integrados de pagamento (Mercado Pago e Asaas) para liberação de testes e planos recorrentes[cite: 1, 6].

## 📂 Estrutura dos Fluxos (n8n)
Na pasta deste repositório, você encontrará os arquivos JSON contendo a arquitetura completa dos fluxos para importação direta no n8n.
